# Smart Budget Buddy Assistant

## About

This project helps users understand spending using CSV files.

The program can:
- analyse spending
- show spending categories
- give basic finance advice
- calculate savings

## Tools Used

- Python
- Pandas
- Gradio
- Google Colab

## How to Run

1. Open notebook in Google Colab
2. Run all cells
3. Upload CSV file
4. Use the buttons in Gradio
